# AGENTS.md

Antes de trabalhar neste repositório, leia nesta ordem:
1. `.ai/PROJECT_CONTEXT.md`
2. `.ai/CURRENT_STATE.md`
3. `.ai/DECISIONS.md`

Regras operacionais:
- Este repo é o ChefPrep canônico no Project Mesh.
- Não use `brguma/app-creator` como implementação atual sem decisão explícita.
- Não duplique aqui o CORE global do BANCO IA; consulte-o quando disponível.
- Antes de mudança funcional relevante: consultar BANCO IA, concorrentes/análogos e Gate 0.
- Preservar IndexedDB, migrações de seed, offline/PWA e integridade do matching.
- Usar branch + commit + PR; não fazer push direto em `main` por padrão.
- Atualizar `.ai/CURRENT_STATE.md` em marcos materiais para manter o handoff confiável.
